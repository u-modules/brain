# Projects 안내

목표와 종료 시점이 있는 작업의 맥락, 결정 이유, 진행 결과를 기록합니다. 소프트웨어 개발 외의 개인 프로젝트도 포함합니다.

## 작성 예시

- 개인 서비스의 목표·요구 사항·기술 선택 이유
- 학습 자료를 제작하거나 행사·스터디를 준비하는 계획
- 선택한 방법, 대안, 결과와 회고

## 기본 형태

목표, 현재 상태, 결정과 근거, 다음 작업, 관련 문서 중 필요한 항목만 작성합니다. 문서가 많아지면 프로젝트별 하위 폴더와 시작 문서를 만듭니다.

## 다른 폴더와의 구분

프로젝트 밖에서도 재사용할 개념은 Notes/, 날짜별 활동은 Journal/에 작성하고 연결합니다. 공개 문서에는 고객 정보·사내 자료·비공개 저장소 내용이 포함되지 않도록 합니다.
