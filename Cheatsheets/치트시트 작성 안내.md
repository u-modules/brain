# 치트시트 작성 안내

개발·학습 중 자주 찾는 명령, 문법, 단축키, 핵심 비교를 빠르게 확인할 수 있도록 정리합니다.

## 작성 예시

- Git의 자주 쓰는 조회·복구 명령
- TypeScript 문법과 짧은 사용 예
- SQL 조회 문법 비교
- 자격증 과목의 헷갈리는 개념 비교표

## 기본 형태

주제와 적용 버전·환경이 필요하면 먼저 적고, `목적 | 명령·문법 | 주의점` 형태의 표나 짧은 코드 예시를 사용합니다. 긴 원리 설명은 Notes/에 작성하고 연결합니다.

코드·명령 예시는 검증 여부를 구분하고, 파일 삭제나 이력 변경처럼 결과가 큰 명령은 실행 결과와 주의점을 함께 적습니다. 실제 인증 키·개인 경로·회사 서버 주소 대신 의미가 분명한 예시 값을 사용합니다.

분야는 `개발/프론트엔드`, `개발/백엔드` 같은 태그로 표시합니다. 치트시트라는 이유만으로 관련 없는 분야 태그를 붙이지 않습니다.
