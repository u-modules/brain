# Journal 안내

특정 날짜에 무엇을 배우고 진행했는지 기록합니다. 사용자가 기록을 요청했을 때 작성하며, 과거 일지를 임의로 만들지 않습니다.

## 작성 예시

- 오늘 학습한 범위와 남은 질문
- 해결한 문제와 다음에 할 일
- 자격증 공부의 진도와 복습할 항목

일지는 `YYYY-MM-DD.md`로 작성합니다. 날짜가 핵심인 기록을 담고, 재사용할 지식은 Notes/나 Certifications/에 따로 정리해 연결합니다.

개인 일정·감정·회사 업무 내용이 섞이기 쉬우므로 공개 대상인지 먼저 확인합니다. 민감한 내용은 공개용 문서로 옮기지 않습니다.
