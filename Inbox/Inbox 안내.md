# Inbox 안내

아직 정리하지 않은 메모·질문·아이디어를 임시로 모읍니다. 처음부터 완성된 문서를 쓸 필요는 없습니다.

## 작성할 내용

- 이해하지 못한 개념이나 나중에 확인할 질문
- 읽을 자료의 링크와 관심을 가진 이유
- 대화·학습에서 얻은 내용을 정리하기 전의 초안

## 정리 기준

- 재사용할 개념·해결 방법 → Notes/
- 자격증 시험 범위·학습 계획·오답의 이유 → Certifications/
- 명령·문법을 빠르게 찾아보는 요약 → Cheatsheets/
- 목표와 종료 시점이 있는 작업 → Projects/
- 날짜별 학습·작업 기록 → Journal/

공개할 때는 원문 복사, 출처 없는 주장, 개인정보가 없는지 검토합니다. 분류를 마쳤다고 원본을 임의로 삭제하지 않습니다.
