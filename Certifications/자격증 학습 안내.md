# 자격증 학습 안내

자격증 취득을 위한 시험 범위·학습 순서·개념 정리·오답 분석을 작성합니다. 자격증은 개발 분야로 한정하지 않습니다.

## 작성 예시

- 자격증별 공식 안내·출제 범위 링크와 확인 날짜
- 과목별 학습 순서와 복습할 개념
- 틀린 이유와 올바른 접근 방법을 자신의 말로 정리한 노트

자격증이 정해지면 이름을 문서 제목에 넣습니다. 관련 문서가 여러 개 쌓일 때만 해당 자격증의 하위 폴더를 만듭니다. 예시 이름만 보고 시험 일정이나 합격 기준을 만들어 넣지 않습니다.

## 노트에 담을 내용

목표 시험·과목, 다룰 개념, 핵심 요약, 혼동한 부분, 근거가 된 공식 자료를 필요한 만큼 적습니다. 분야 태그와 함께 `자격증/자격증명`처럼 실제 이름을 사용합니다.

시험 일정·응시 자격·출제 기준은 해당 시행기관의 최신 공식 자료에서 확인하고 확인 날짜를 남깁니다. 개인 접수 번호·성적표·신분 정보는 공개용 노트에 넣지 않습니다.

## 다른 폴더와의 구분

시험과 무관하게 재사용할 개념 설명은 Notes/, 마지막으로 빠르게 복습할 문법·명령 요약은 Cheatsheets/에 두고 연결합니다. 유료 교재나 문제 원문 전체를 복제하기보다 출처와 직접 정리한 설명을 남깁니다.
