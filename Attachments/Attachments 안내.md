# Attachments 안내

노트에서 사용하는 이미지·도표·첨부 자료를 보관합니다. 텍스트 설명과 출처는 해당 노트에 작성하고 첨부 파일을 연결합니다.

## 작성 예시

- 직접 만든 설명용 도표
- 공개해도 되는 화면의 스크린샷
- 재배포 권한을 확인한 참고 파일

파일명은 내용을 알아볼 수 있게 짓고, 같은 이름의 파일을 덮어쓰지 않습니다. 첨부 파일도 Git과 공개 대상 검토에 포함됩니다.

공개 이미지에는 계정·토큰·고객 정보가 보이지 않는지 확인합니다. 개인 성적표·접수증·업무 내부 자료와 같은 비공개 첨부는 공개용 첨부 폴더에 두지 않습니다.
